# Python From Zero

轻量自学路径 + 可运行练习。

## 准备
- 已预置：可直接运行的笔记本 `notebooks/01_basics.ipynb`
- 如需虚拟环境：
  - Linux/macOS: `python3 -m venv .venv && source .venv/bin/activate`
  - Windows (PowerShell): `py -m venv .venv; .venv\\Scripts\\Activate.ps1`
  - 若报 `ensurepip is not available`，按系统安装 `python3-venv` 后重试

## 学习路径（精简版）
1. 基础语法：变量、类型（int/float/str/bool）、输入输出、表达式、条件、循环
2. 组合数据：list/tuple/dict/set、切片、遍历、推导式
3. 函数：参数、返回值、作用域、文档字符串、类型注解
4. 模块与包：标准库（`math`、`random`、`datetime`、`pathlib`）
5. 文件与异常：读写文本/CSV、`with`、`try/except`
6. 面向对象：类、实例、继承、数据类
7. 实用库：`numpy`、`pandas`、`matplotlib`
8. 项目化：虚拟环境、依赖、脚本化、测试

## 使用方式
- 直接在编辑器中打开：`notebooks/01_basics.ipynb`
- 也可本地运行 `jupyter lab` 或在编辑器选择 Python 内核进行执行
